# Implementation Guide

## 1. Overview

This document defines the implementation approach for building the chatbot-based autonomous agent PoC.

The goal is to complete the system within a short development timeline while maintaining the core capabilities:

- Client chatbot
- Client Agent
- A2A Gateway
- PM Agent orchestration
- Specialist agents
- Llama reasoning
- PostgreSQL persistence
- pgvector semantic memory
- Proposal generation

This implementation intentionally avoids enterprise complexity.

# 6. Agent Runtime Implementation

All agents inherit from a common base class.

Example:

```python
class BaseAgent:

    def __init__(
        self,
        name,
        goal,
        memory,
        llm,
        tools
    ):
        self.name = name
        self.goal = goal
        self.memory = memory
        self.llm = llm
        self.tools = tools
```

---

# 7. Base Agent Flow

Every agent executes:

```python
def execute(task):

    context = memory.retrieve(task)

    prompt = build_prompt(
        task,
        context
    )

    response = llm.generate(prompt)

    memory.save(response)

    return response
```

---

# 8. Llama Integration

Create a common Llama client.

Example:

```python
class LlamaClient:

    def generate(prompt):

        response = model.generate(
            prompt
        )

        return response
```

---

Agents never directly call Llama.

Flow:

```
Agent

↓

LLM Client

↓

Llama

↓

Agent
```

# 19. PoC Simplifications

To finish quickly:

## Use

- Single PostgreSQL database
- Single FastAPI application initially
- Simple REST communication
- Local Llama instance/API
- JSON-based messages

---

## Avoid

- Kafka
- RabbitMQ
- Kubernetes
- Vector DB servers
- Workflow engines
- Complex authentication

---

# 20. Final Implementation Goal

The completed PoC should demonstrate:

```
Client

↓

Chatbot

↓

Client Agent

↓

A2A Gateway

↓

PM Agent

↓

Specialist Agents

↓
```

The focus is not infrastructure.

The focus is proving that autonomous agents can communicate, reason, collaborate, and complete a business workflow through natural conversation.
