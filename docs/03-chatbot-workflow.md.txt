# Chatbot Workflow

## 1. Overview

The chatbot workflow is the heart of this Proof of Concept.

Instead of users interacting with multiple autonomous agents, the entire experience is presented through **two conversational interfaces**:

1. Client ↔ Client Agent (Visible)
2. Client Agent ↔ Project Manager Agent (Internal)

The client only interacts with the Client Agent.

The Client Agent acts as:

- Requirement Analyst
- AI Assistant
- Communication Bridge
- Memory Manager
- Gateway to the Company Network

The Client Agent communicates with the Project Manager Agent through the A2A Gateway, while the Project Manager orchestrates the remaining specialist agents.

# 22. Workflow Summary

This chatbot workflow ensures:

- The client interacts with only one visible AI assistant.
- The Client Agent intelligently filters and answers internal questions whenever possible.
- The Project Manager orchestrates specialist agents autonomously.
- All reasoning is performed using Llama.
- PostgreSQL stores transactional data.
- pgvector stores semantic project knowledge.
- The client is only involved when human input is genuinely required.
- The final outcome is an approved project summary followed by a generated proposal.

This workflow keeps the PoC simple while demonstrating autonomous multi-agent collaboration across independent organizational networks.
