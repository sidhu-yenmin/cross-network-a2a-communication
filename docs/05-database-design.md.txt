# Database Design

## 1. Overview

The chatbot-based A2A PoC uses **PostgreSQL** as the primary database for all transactional data.

PostgreSQL stores:

- Users
- Projects
- Requirements
- Chat Sessions
- Chat Messages
- Agent Sessions
- Agent Tasks
- Proposals
- Approvals
- Gateway Logs

Unlike many AI applications, **chat messages are NOT stored in the vector database**.

Only summarized knowledge is embedded into pgvector.

# 20. Why PostgreSQL?

PostgreSQL is sufficient for this PoC because it provides:

- ACID-compliant transactions
- JSONB support for flexible data
- Native UUID support
- Excellent indexing
- Easy integration with FastAPI and SQLAlchemy
- Support for the pgvector extension in the same database

Using PostgreSQL avoids introducing additional infrastructure while keeping the design simple and maintainable.
